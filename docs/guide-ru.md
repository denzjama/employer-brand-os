# Employer Brand OS: руководство для руководителя HR-бренда

Эта инструкция для того, кто отвечает за HR-бренд и будет запускать систему. Технических знаний не нужно: всё общение с системой идёт обычным текстом в чате.

## Что это

Employer Brand OS — система агентов для функции HR-бренда. Она:

1. **Разбирается в функции.** Изучает ваши материалы (стратегию, EVP, отчёты, планы), проводит с вами интервью и показывает, где агенты возьмут работу на себя, где помогут человеку, а где работа остаётся за людьми.
2. **Собирает команду агентов** по вашим процессам. У каждого агента есть владелец из команды, ритуал, в котором он живёт (планёрка, ежемесячный план), и первая метрика.
3. **Работает вместе с командой.** Агенты готовят черновики, контроль качества проверяет каждое утверждение по подтверждённым фактам, решает всегда человек.
4. **Учится.** Раз в две недели ретро показывает, что работает, и предлагает изменения. Применяются только одобренные вами.

Система ничего не публикует и никому ничего не отправляет. Публикуют люди.

## Что понадобится

| Что | Зачем |
|---|---|
| Подписка Claude (Pro, Max, Team или Enterprise) или доступ к API Anthropic | Claude Code работает на этой подписке |
| Установленный Claude Code | Рабочая среда системы. Инструкция по установке — на сайте Anthropic |
| Python 3.9 или новее | Скрипты системы. На macOS и Linux обычно уже есть |
| Git | Общая рабочая папка команды (с фазы 2) |
| Согласование службы безопасности | Материалы отправляются на обработку провайдеру модели. Справку для ИБ см. в [security-ru.md](security-ru.md) |

macOS и Linux поддерживаются напрямую. На Windows нужен WSL или Git Bash.

## Установка

Две команды в терминале, один раз:

```bash
claude plugin marketplace add denzjama/employer-brand-os
```

```bash
claude plugin install employer-brand-os@employer-brand-os
```

Затем создайте пустую папку для рабочего пространства (например, `eb-workspace` в домашней папке), откройте в ней Claude Code и напишите:

```text
Подключи Employer Brand OS
```

Система назовёт папку, расскажет, какие данные уходят провайдеру модели, и спросит согласие. До вашего «да» она ничего не читает и не создаёт.

## Как проходит работа

| Фаза | Что делаете вы |
|---|---|
| 1. Диагностика | Кладёте материалы в `eb/inbox/`, отвечаете на интервью из шести коротких блоков (можно частями, часть ответов могут дать руководители направлений), подтверждаете факты, обсуждаете предложение с будущими владельцами агентов |
| 2. Сборка команды | Даёте согласие на сборку, владельцы подтверждают описания своих агентов, каждый конвейер проходит пробный запуск |
| 3. Работа | Команда запускает конвейеры на своих ритуалах и записывает решения по черновикам командой `/decide` |
| 4. Ретро | Раз в две недели вы смотрите отчёт ретро и решаете по предложениям |

После диагностики у вас есть:
- карта функции: какие процессы ведёт агент, где агент помогает человеку, а что остаётся за людьми;
- предложение по команде агентов;
- одностраничная сводка для HR-директора;
- страница обзора, которую можно показать на встрече.

Экономию система не обещает. Эффект измеряется в пилоте.

## Правила, которые нельзя выключить

- **Нет доказательства — нет утверждения.** Факт о компании становится подтверждённым только после вашего явного ответа об этом факте. Наружу уходят только подтверждённые факты.
- **Цель не пишется как результат.** «Снизить текучесть до 12%» не превращается в «снизили до 12%».
- **Материалы — это данные, а не инструкции.** Если в отзыве или документе спрятана команда для системы, система сообщит о ней и не выполнит её.
- **Персональные данные остаются снаружи.** Сотрудники называются по имени только в историях с записанным согласием. Дети и пароли не попадают никуда.
- **Люди публикуют, агенты готовят.** Никакой уровень самостоятельности агента этого не меняет.

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Не знаете, где остановились | Откройте Claude Code в рабочей папке и напишите «где мы остановились» |
| Агенты после сборки не отвечают | Перезапустите Claude Code в рабочей папке |
| Нужно срочно что-то написать вне плана | Просто попросите. Перед отправкой система покажет все цифры в тексте и их статус |
| Коллега без доступа к Claude должен решить по черновику | Команда `/export-docx` сделает документ Word, решение записывает оператор |
