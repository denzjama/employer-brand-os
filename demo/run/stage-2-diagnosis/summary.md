# Этап 2: диагностика функции — итоговое сообщение системы

Диагностика прошла целиком: интервью по вашим ответам из файла, оценки и зоны, предложение по команде, опросник для владельцев, сводка для HR-директора и страница обзора. Предложение записано как утверждённое вами с условием проверки с владельцами. Раунд подтверждения фактов пропущен, как вы просили.

**Функция.** Задача — чтобы на терминал шли и оставались операторы кранов и докеры. Команда из 6 человек, отчитывается HR-директору. Главные проблемы: на отзывы не отвечают, истории ждут согласований 3–4 недели, квартальный отчёт съедает 2–3 дня.

**Карта процессов.** Разобрано 12 процессов:
- **Ведёт агент (3):** мониторинг отзывов, квартальный отчёт, контент-план.
- **Ведёт человек, агент помогает (8):** истории, ответы на отзывы, Telegram, дизайн-адаптации, сайт, рассылки, спецпроекты, подрядчики.
- **Остаётся за людьми (1):** мероприятия для колледжей.

**Первая волна, 6 агентов:**

| Агент | Владелец |
|---|---|
| Мониторинг отзывов | менеджер по репутации |
| Ответы на отзывы | менеджер по репутации |
| Истории сотрудников | контент-менеджер по историям |
| Отчёт для HR-директора | вы |
| Контроль качества | вы |
| Коуч внедрения | вы |

Все ритуалы встроены в понедельничную планёрку или в квартальный отчёт. Агенты связаны пятью конвейерами: отзыв → ответ, история, квартальный отчёт, исправление ошибки в бренд-ядре для всех агентов, разбор ваших решений на ретро. Каждый внешний текст проходит контроль качества, публикует всегда человек.

Во вторую волну ушли SMM, сайт и рассылки: у их владельцев нет доступа к инструменту, и они настроены скептически. Дизайн и работа с подрядчиками ждут данных, а у подрядчиков ещё и нет владельца.

**Что нужно решить вам:**
1. **Персональные данные в историях.** По вашим словам, служба безопасности согласовала Claude без персональных данных сотрудников, а в расшифровках интервью они есть. Я предложил обезличивать расшифровки или получить отдельное согласование. Спросить вас я не мог, поэтому решение записано как ожидающее, и до него агент историй работает только с обезличенными текстами.
2. **Подтверждение фактов.** Подтверждено 0 из 40. Пока раунд не пройден, черновики ответов и историй остаются внутренними пробами и наружу не уходят.
3. **Ваша нагрузка.** На вас три агента, и вы же запускаете агентов менеджера по репутации, потому что у неё нет доступа. Если это много, можно купить ей доступ или передать эту роль контент-менеджеру по историям.
4. **Остальное:** оценка часов от дизайнера, обращение «вы» или «ты», учётные данные в плане онбординга I квартала. Всего открытых вопросов 17, они в `open-questions.md`.

Ещё одно расхождение для раунда подтверждения: в интервью стипендии для колледжа названы планом, а в презентации для студентов они поданы как уже действующие.

**Следующий шаг:** провести проверку с тремя владельцами по `validation.md`, по 20–30 минут с каждым или письменно, и пройти раунд подтверждения фактов. После этого можно собирать команду.
