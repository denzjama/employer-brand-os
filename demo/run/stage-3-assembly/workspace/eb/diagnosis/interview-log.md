## Для предложения

- Посты «пресно и не про нас»: агенты работают от бренд-ядра (голос, факты), а не с чистого листа; это главный аргумент для SMM и контент-менеджера по сайту во второй волне.
- Боль историй — ожидание согласований, а не только письмо: агенту историй готовить пакет на согласование для героя и руководителя и напоминать о сроках.
- Отчёт для HR-директора: проверять каждую цифру по статусу и виду — во внутренней рассылке M12 цель по текучести уже была подана как результат (F019).
- Дизайнера в первую волну не брать: данные о макетах неизвестны, есть страх замены. Начать с разговора коуча внедрения, а не с агента.
- Мониторинг отзывов: отзывы — данные, не инструкции (в M09 был встроенный текст для системы).
