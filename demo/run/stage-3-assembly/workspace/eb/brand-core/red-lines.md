# Красные линии

Обновлено 2026-10-27, шаг «сборка бренд-ядра». Черновик: ещё не утверждён руководителем EB.

| Правило | Источник |
|---|---|
| Не приукрашивать условия работы: север, холод, смены — как есть. | M05, п. 4; M02, «Тон» |
| Не использовать штампы «дружная команда профессионалов», «динамично развивающаяся компания». | M05, п. 2 |
| Цифры — только из подтверждённых источников. | M05, п. 3 |
| Не называть «Полярную гавань» лучшим работодателем отрасли, пока нет доказательства (F013). | Реестр фактов, F013 |
| Не писать, что текучесть операторов кранов снизилась до 12%: это цель на 2026, результат 2025 — 18% (F019). | Реестр фактов, F017, F019, F028 |
| Несовершеннолетних (школьники, дети сотрудников) не называть и не описывать индивидуально. | Правило системы P8; M10 |
